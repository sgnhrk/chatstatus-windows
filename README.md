# ChatStatus for Windows

Windows のタスクバー上に、Codex の実行件数・使用率・完了して未確認の件数を常時表示する日本語アプリです。

A lightweight Japanese Windows taskbar overlay for Codex activity, recorded usage limits, and unacknowledged completions. Unofficial; not affiliated with OpenAI.

## 起動と操作

[Releases](https://github.com/sgnhrk/chatstatus-windows/releases) から ZIP をダウンロードし、書き込み可能な場所へ展開して `ChatStatus.exe` を起動します。Windows 10 / 11、.NET Framework 4.x が必要です。追加パッケージや API キーは不要です。EXE は未署名です。Windows 11 の1画面・下部タスクバーで確認しました。

| 表示 | 内容 |
| --- | --- |
| CDX 実行 | ローカル記録から読み取った実行件数 |
| 使用 / 記録値 | 最後に記録された Codex の使用率 |
| 完了・未確認 | 確認済みにしていない完了通知の件数 |

- 数値部分をクリックすると詳細が開きます。開くだけでは確認済みになりません。
- 完了一覧で項目を選び「選択を確認済みに」を押すと件数が減ります。「すべて確認済みに」も使えます。
- 未確認通知と確認状態は保存され、再起動後も保持されます。
- 数値部分をドラッグすると位置を変更・保存できます。右クリックで詳細・位置リセット。
- トレイの C アイコンから、全件の確認・更新・終了などを操作できます。
- 詳細画面の × はトレイへ戻ります。終了はトレイメニューから。

## 完了通知

最初の読込が終わってから、新しく検出した Codex の完了イベントを通知・集計します。開始状態を更新時に見逃しても、完了イベントが記録されていれば集計します。同じ作業を続けて実行した場合は、それぞれの実行の完了を数えます。中断は含みません。

初回読込時の過去の完了は追加しません。アプリ終了中の新しい完了を遡って追加する機能はありません。保存済みの未確認通知は次回起動後も残ります。

Windows のバルーン通知を閉じても確認済みにはなりません。通知設定や集中モードにより通知が見えなくても件数は保持されます。

v0.1.0 の日時指定リマインダーを廃止し、作業の完了・未確認件数に置き換えました。旧 `data/reminders.json` は変更・削除しません。

## 取得範囲と制限

`CODEX_HOME`（未設定なら `%USERPROFILE%/.codex`）のセッション記録と `session_index.jsonl` を5秒間隔で読みます。直近8日分のフォルダーの最近更新された30ファイルが対象です。直近7日の作業を最大12件表示します。

開始・完了・中断イベントから状態を表示し、実行中の記録が10分止まると「状態不明」と表示します。進捗率・承認待ち・クラウドのみの作業は取得できません。

使用率は `token_count` に含まれる最後の記録値です。サーバーへ現在値を問い合わせません。詳細画面に記録時刻・リセット日時・期限経過を表示します。

**通常の ChatGPT / Work の進行状況・使用量・完了通知の自動取得は未対応です。** タスクバーと詳細画面から未連携欄を削除しました。通常の ChatGPT の通知は[公式アプリの通知・Activity](https://learn.chatgpt.com/docs/notifications)を併用してください。

ローカル記録の形式は公式な外部連携契約ではなく、Codex の更新で動作が変わる可能性があります。

## タスクバーと保存

背景透明のウィンドウをタスクバー上に重ねます。表示領域は予約しません。他のアイコンや CPU モニターと重なる場合は空いている場所へドラッグしてください。メイン画面のタスクバーに追従し、全画面アプリやタスクバーの自動非表示中は隠します。複数画面・特殊な配置は未検証です。ライト・ダークテーマは Windows 設定から読みます。

認証情報の読取、ネットワーク通信、テレメトリー、課金 API の呼び出しはありません。EXE と同じフォルダーの `data/completions.json` に完了通知・作業名・確認状態、`data/taskbar-position.txt` に位置を保存します。個人データと実画面のプレビューはリポジトリに含みません。

自動起動は設定しません。必要なら EXE のショートカットを Windows のスタートアップフォルダーへ入れてください。更新前・削除前にはトレイから終了します。データを残す場合は `data` を保存してください。

## ビルドと検証

```powershell
./Build.ps1
$test = Start-Process ./dist/ChatStatus.exe -ArgumentList '--test' -PassThru
$test.WaitForExit()
$test.ExitCode
Get-Content ./dist/test-results.txt
```

Windows 標準の .NET Framework コンパイラーを使い `dist/ChatStatus.exe` を出力します。再ビルド前に実行中の EXE を終了してください。

テストは増分読込、部分的な JSON、使用量、完了通知の重複防止・複数件集計・保存・再起動・確認操作、中断の除外、破損データの保護を検証します。タスクバーと通知の表示は Windows 上で別途確認してください。

`--preview` は作業名を含む画像などを EXE の隣へ保存します。これらを公開しないでください。
