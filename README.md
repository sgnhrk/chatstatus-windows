# ChatStatus for Windows

Windows のタスクバー上に、Codex の作業件数・使用率・リマインド件数を常時表示する小さな日本語アプリです。CPU モニターのように、数値を見ながら他の作業を続けられます。

A lightweight Japanese Windows taskbar overlay for Codex activity, recorded usage limits, and local reminders. Built with C# and Windows Forms. Unofficial; not affiliated with OpenAI.

## ダウンロードと起動

1. [Releases](https://github.com/sgnhrk/chatstatus-windows/releases) から ZIP をダウンロード。
2. 書き込み可能なフォルダーへ展開。
3. `ChatStatus.exe` を起動。API キーや追加パッケージは不要です。

Windows 10 / 11 と .NET Framework 4.x が必要です。Windows 11 の1画面・下部タスクバーで動作確認しました。配布 EXE は署名されていません。

## 表示と操作

| 表示 | 内容 |
| --- | --- |
| CDX 実行 | ローカル記録から読み取った実行中の件数 |
| 使用 / 記録値 | Codex の最後に記録された使用率 |
| リマインド | 未完了件数。期限到来は `!` 付きで表示 |
| ChatGPT | 自動連携は未対応のため「未連携」 |

- 数値部分をクリックすると詳細画面が開きます。
- ドラッグでタスクバー上の位置を変えられます。位置は次回起動にも引き継ぎます。
- 数値部分を右クリックすると、詳細と位置リセットを選べます。
- トレイの C アイコンから、リマインド追加・更新・終了などを操作できます。
- 詳細画面の × はトレイへ戻ります。終了はトレイメニューから。
- アイコンが見つからない場合は、通知領域の隠れたインジケーターを確認してください。

## 連携の範囲

### Codex

`CODEX_HOME`（未設定なら `%USERPROFILE%/.codex`）のローカルセッション記録と `session_index.jsonl` を5秒間隔で読み取ります。開始・完了・中断イベントから作業状態を表示します。実行中の記録が10分止まると「状態不明」と表示します。進捗率や承認待ち、クラウドのみの作業は取得できません。

直近8日分のフォルダー内の最近更新された30ファイルを対象に、直近7日の作業を最大12件表示します。使用率は `token_count` に含まれる最後の記録値です。サーバーへ現在値を問い合わせません。詳細画面に記録時刻とリセット日時を表示し、期限経過も明示します。

完了通知は、アプリが実行中を検出してから完了へ変化した場合に出ます。起動前の完了を遡って通知しません。

ローカル記録の形式は公式な外部連携契約ではなく、Codex の更新で動作が変わる可能性があります。

### ChatGPT

**通常の ChatGPT のチャット進行状況・使用量・登録済みタスクの自動取得は未対応です。** ChatGPT と Codex の利用量を同一の数値として扱いません。ChatGPT を開くボタンと、連携状態の表示があります。

通常の ChatGPT の作業通知は、[公式アプリの通知・Activity](https://learn.chatgpt.com/docs/notifications)を併用してください。

### リマインド

このアプリ内で登録する独立したリマインドです。ChatGPT / Codex の予約タスクとは同期しません。PC が起動してアプリが動いている間に Windows のバルーン通知を出します。

終了中・スリープ中に予定時刻を過ぎた未通知項目は、次回起動時に通知します。通知済み項目も「完了」を押すまで一覧に残ります。通知設定や集中モードにより通知が見えない場合があります。日時はPCのローカル時刻です。

## タスクバー表示の仕組み

背景透明のウィンドウをタスクバー上に重ねます。タスクバー内の領域を予約する方式ではありません。他のアイコンや CPU モニターと重なった場合は、空いている場所へドラッグしてください。

メイン画面のタスクバーに追従し、全画面アプリやタスクバーの自動非表示中は隠します。複数画面や特殊なタスクバー配置は未検証です。ライト・ダークテーマを Windows の設定から読み取ります。

## プライバシーと保存

- 認証情報を読みません。
- ネットワーク通信、テレメトリー、課金 API の呼び出しはありません。
- 「ChatGPT を開く」の操作時のみブラウザーを起動します。
- EXE と同じフォルダーの `data/reminders.json` にリマインドを保存します。
- `data/taskbar-position.txt` に表示位置を保存します。
- 個人データ、作業名を含む実画面のプレビュー、利用者の記録はリポジトリに含みません。

自動起動は設定しません。必要なら EXE のショートカットを Windows のスタートアップフォルダーへ入れてください。削除するときはトレイから終了し、展開フォルダーを削除します。データを残す場合は先に `data` を保存してください。

## ビルドと検証

Windows PowerShell または PowerShell で：

```powershell
./Build.ps1
$test = Start-Process ./dist/ChatStatus.exe -ArgumentList '--test' -PassThru
$test.WaitForExit()
$test.ExitCode
Get-Content ./dist/test-results.txt
```

出力は `dist/ChatStatus.exe`。Windows 標準の .NET Framework コンパイラーを使用します。実行中の EXE は上書きできないため、再ビルド前に終了してください。

テストは開始・完了イベント、部分的な JSON 行、増分読込、使用量、壊れた行、リマインドのシリアライズを検証します。実際のタスクバー配置・通知の見え方は Windows 上で別途確認してください。

`--preview` は動作確認用で、実際の作業名が入る詳細画面の画像などを EXE の隣へ保存します。これらを公開しないでください。
